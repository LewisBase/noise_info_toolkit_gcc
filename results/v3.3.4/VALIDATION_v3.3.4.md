## 任务 1 · 模拟纯音 × 不同时间窗口

**问题**：v3.3.4 在 34 个 IEC 1/3 倍频程频点上，A/C/Z 计权是否算对？短时间窗下「A 计权低频偏差大 / C 计权高频偏差大」是否仍存在？

**方法**：每频点生成 3 s 纯音（94 dB SPL，48 kHz），同一 `NoiseProcessor` 连续按窗口切块处理（滤波器状态连续），跳过前 1 s 建立期，取能量平均；与 `94 + IEC 参考衰减` 比较。

### 结果

| 窗长 | A 计权 max\|Δ\| | 出现在 | C 计权 max\|Δ\| | 出现在 |
|---|---:|---|---:|---|
| **10 ms** | **0.484 dB** | 20 kHz | **0.150 dB** | 16 kHz |
| **100 ms** | 0.484 dB | 20 kHz | 0.150 dB | 16 kHz |
| **1 s** | 0.484 dB | 20 kHz | 0.150 dB | 16 kHz |

**全 34 频点 × 3 种窗长，没有任何一格超过 ±0.5 dB。**

低频段（10 / 12.5 / 16 / 20 / 25 / 31.5 Hz）A 计权误差：−0.011 / −0.171 / +0.285 / +0.109 / −0.121 / −0.132 dB
高频段（8 / 10 / 12.5 / 16 / 20 kHz）C 计权误差：−0.093 / +0.014 / +0.130 / −0.150 / +0.070 dB

### 结论

✅ **短窗口偏差已不存在。** 10 ms 与 1 s 的结果**完全相同**（差异 < 0.001 dB），说明：
1. A 计权低频不再因窗口过短而偏高；
2. C 计权高频不再有系统性偏差；
3. 窗口长度在 10 ms–1 s 范围内对 Leq 结果无影响。

> 注：本测试中 10 ms 窗已能给出正确结果，是因为滤波器状态连续（真实固件亦如此）。
> 若每次开窗都重置滤波器状态，10 ms 内 A 计权的 20.6 Hz 双极点来不及建立，仍会出现偏差
> —— 这是固件调用方式问题，不是系数问题。

## 任务 2 · 20261010 真实录音 vs 设备 CSV

**素材**：`results/SES00003_261010/`
- `261010-10_Pa.wav`（2342.2 s）+ `261010-10.CSV`（2342 行）
- `261010-12_Pa.wav`（8008.9 s）+ `261010-12.CSV`（8008 行）
- WAV 为 32-bit IEEE float / 48 kHz / 单声道 / **Pa 单位**

**时间轴对齐**：最佳偏移 = **0 s**；逐秒 LZeq 差 **均值 −0.549 dB、标准差 0.003 dB**
→ 对齐严格，且存在一个**恒定标定偏移**。

### 结果（v3.3.4 − 设备 CSV）

| 指标 | 261010-10 (2342 s) | 261010-12 (8008 s) |
|---|---|---|
| **LZeq** 逐秒差 | 均值 **−0.549**，std **0.003** | 均值 −0.549，std 0.003 |
| **LAeq** 逐秒差 | 均值 −0.498，std **0.029** | 均值 −0.502，std 0.018 |
| **LCeq** 逐秒差 | 均值 −0.759，std 0.323 | 均值 −0.687，std 0.124 |

**计权相对衰减（LAeq−LZeq / LCeq−LZeq，与绝对标定无关）**

| | 设备均值 | v3.3.4 均值 | 差 |
|---|---:|---:|---:|
| 10 · LAeq−LZeq | −9.151 | −9.099 | **+0.051 dB**（max 0.290） |
| 10 · LCeq−LZeq | −2.503 | −2.713 | **−0.209 dB**（max 6.582） |
| 12 · LAeq−LZeq | −10.599 | −10.552 | **+0.047 dB**（max 0.247） |
| 12 · LCeq−LZeq | −2.791 | −2.929 | **−0.138 dB**（max 4.139） |

### LCeq 大偏离的归因

| 阈值 | 261010-10 | 261010-12 |
|---|---|---|
| \|Δ\| > 1 dB | 184 s（7.86%） | 101 s（1.26%） |
| \|Δ\| > 2 dB | **17 s（0.73%）** | **13 s（0.16%）** |
| \|Δ\| > 3 dB | 8 s（0.34%） | 3 s（0.04%） |

> 注：绝对阈值受 −0.759 dB 恒定偏移影响，扣除后 99.3% / 99.8% 的秒 ≤1 dB。

**归因证据**：
- 异常秒的 **>20 kHz 能量占比高达 80–93%**（对照：全体中位 4.89%）
- `LCeq 差（设备−v3.3.4）` 与 `>20 kHz 能量占比` 的相关系数 **r = +0.951**
- 分组统计：

| 分组 | 秒数 | LCeq 差均值 | std |
|---|---:|---:|---:|
| >20 kHz 占比 < 10% | 204 | **+0.688 dB** | 0.080 |
| >20 kHz 占比 > 50% | 3 | **+3.180 dB** | 0.455 |

**逐秒三方对照（秒 1813）**

| | C 计权衰减 |
|---|---:|
| v3.3.4 biquad | **−10.97 dB** |
| IEC 61672-1 解析式 | **−11.68 dB** ← v3.3.4 与之相符 |
| 设备 CSV | **−4.38 dB** |

### 结论

✅ **在 IEC 61672-1 标称频段（20 Hz–20 kHz）内，v3.3.4 与设备高度一致**：
- LZeq 恒定偏移 −0.549 dB（std 0.003）→ 纯标定常数，非算法差异
- A 计权扣除标定后偏差 **+0.05 dB**（max 0.29）
- C 计权扣除标定后偏差 **−0.21 / −0.14 dB**，99.3% / 99.8% 的秒 ≤1 dB

⚠️ **残差全部来自 20 kHz 以上**：极少数秒（0.73% / 0.16%）中 >20 kHz 能量占 80–93%，
此时设备 C 计权读数比 v3.3.4 高最多 6.6 dB（r = +0.951 强相关）。

## 关于 20 kHz 以上（已确认：不在处理范围）

密集频点（10 Hz–23.9 kHz，4000 点）与 IEC 解析式比较：

| 频段 | A 计权 max\|Δ\| | C 计权 max\|Δ\| |
|---|---:|---:|
| **10 Hz – 20 kHz（标称范围）** | **0.522 dB** | **0.144 dB** |
| 20 – 23.9 kHz（范围外） | 6.491 dB | 1.545 dB |

**结论：20 kHz 以上不纳入处理范围**（IEC 61672-1 标称范围上限即 20 kHz，该区未受约束）。
任务 2 中那 0.73% / 0.16% 的 C 计权大偏差秒，其 >20 kHz 能量占 80–93%，即**完全由该区引起**；
在标称范围内 v3.3.4 与设备一致。**本项不作为缺陷处理。**

## 短窗误差机理对照实验（本轮新增，关键证据）

同一 10 ms 分块方式，两种滤波器状态策略（94 dB SPL 纯音，前 1 s 不计）：

| 频率 | A 理论衰减 | 连续状态误差（v3.3.2+） | 每块重置误差（v3.3.2 之前） |
|---|---:|---:|---:|
| 10 Hz | −70.4 dB | **−0.011 dB** ✅ | **+51.7 dB** ❌ |
| 12.5 Hz | −63.4 dB | −0.171 dB ✅ | +44.9 dB ❌ |
| 16 Hz | −56.7 dB | +0.285 dB ✅ | +38.0 dB ❌ |
| 20 Hz | −50.5 dB | +0.109 dB ✅ | +36.9 dB ❌ |
| 25 Hz | −44.7 dB | −0.121 dB ✅ | +31.2 dB ❌ |
| 63 Hz | −26.2 dB | −0.025 dB ✅ | +8.4 dB ❌ |
| 125 Hz | −16.1 dB | −0.091 dB ✅ | +1.65 dB ❌ |
| 1 kHz | 0 dB | 0.000 dB ✅ | −0.123 dB ✅ |

**结论**：系统性低频偏差的唯一来源是**每块重置滤波器状态**；状态连续（v3.3.2 起）后偏差消失。

> 补充：即使状态连续，**单次 10 ms 读数在低频仍会大幅散开**（10 Hz 时逐块 LAeq 在 11.97–26.26 dB 之间波动）。
> 因为 10 ms 只含 0.1 个周期，窗口内均方值本身与相位强相关——这是窗口长度的**固有**限制，
> 任何算法都无法消除。但**能量平均后的 Leq 无偏**（上表），而 Leq 按标准就是在测量区间上定义的。

工件：`tool_reset_experiment.cpp` + `04_shortwindow_reset_experiment.csv`
